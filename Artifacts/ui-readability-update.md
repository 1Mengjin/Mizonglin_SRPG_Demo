# UI可读性调整

- 顶部回合提示增加78%半透明黑底，只保留回合数。携雾、剩余雾源、地面瘴气、溢出和待掉落等常驻文字已移除；详细污染数据仍可在战斗记录中查看。范围说明和技能效果预览单独按需显示在底部黑底提示区。
- 角色卡使用更深底色、白色姓名、较大字体及更宽血条；属性区只显示当前有效攻击、防御、移动和射程，不再重复瘴毒/蚀痕或基础值箭头。
- 原有说明段落改为可点击状态栏：矢量图标、简短名称和层数/剩余回合/次数角标；实际效果在弹窗中查看。包括瘴毒、蚀痕、晕眩、飞行/落地、待切换姿态、攻守形态、反伤、符箓引、濒死、行动、携带元神、净行、技能冷却/次数及敌方特殊机制。无效的零层负面状态不占格；移动预览另有提示图标。
- 只有双方回合切换保留58%黑色全屏半透明遮罩。胜利条件、我方技能头像与敌方技能提示改为独立的简易矩形边框，72%黑色半透明底只绘制在框内，框外场景不压暗；原有动画时长及阻止重复操作的逻辑保持。
- 默认独立窗口与Web画布分辨率改为1920×1080；UI以Screen Space Overlay直接按屏幕绘制并启用像素对齐，保留原有设计尺寸以免整体缩小。头顶血条/飘字的坐标转换已适配，截图入口临时绑定相机并在结束后还原。圆形控件纹理128→512，模型头像256→512并启用4倍抗锯齿。已有128像素角色原图保留，未将简单放大冒充新增图像细节。

验证：运行时/编辑器编译通过；M1–M5与技能规则回归通过；状态展示模型18条断言通过；扩展的实际播放脚本已编译，加入状态栏弹窗与屏幕覆盖绘制检查。Unity许可证仍不可用，此次未运行实际点击或画面验收。
