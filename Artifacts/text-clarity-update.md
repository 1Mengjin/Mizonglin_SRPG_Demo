# 仅调整文字清晰度

按用户澄清，撤回此前3840×2160、Game视图切换和1024纹理精度的尝试。窗口默认保持1920×1080，原生分辨率选项保持原值，圆形控件与模型头像继续使用512精度；未留下自动修改Game视图的脚本。

本次有效产品修改仅为文字绘制：新增SharpText，仍继承并沿用UGUI Text的字号、字型、颜色、换行、布局测量和原有顶点位置，只将字形采样提高到2倍。动态字体图集在UI重建之前统一准备，防止图集更新导致其他文字坐标失效。字体无法提供匹配的细采样时保留标准绘制。

入口仍是BattleDemo.Label；现有技能描述、状态弹窗、教程和其他文字继续通过Text接口使用，不修改文案、面板尺寸或战斗逻辑。

验证：完整运行时/编辑器编译与M1回归通过。`python Artifacts/verify_battle_ui.py --text-clarity` 实际播放确认中文正文使用双倍字形、正文所有顶点位置一致、字号/换行边界/测量高度不变、屏幕分辨率和Canvas缩放不变、默认窗口仍为1920×1080。对比场景中46个非空文字组件使用细采样，另2个为空文字。

已查看实际前后截图：`Artifacts/ui-17-text-before.png`、`Artifacts/ui-18-text-after.png`。最终结果见 `Artifacts/text-clarity-verification.txt`。早期试验中出现的字体缓存显示异常已修正，最终截图已重新生成。
