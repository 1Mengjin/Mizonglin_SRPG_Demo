# 技能与状态说明编辑接口

## 使用

1. 打开Unity菜单「迷踪林战棋 Demo → 技能与状态说明」。关卡设计窗口和BattleDemo Inspector也有入口。
2. 左侧选择需要修改的条目，可筛选主动技能、状态与被动，或搜索名称；如「反伤」「瘴毒」。已从状态栏移除的操作信息和常驻被动条目不再列在编辑窗口中。
3. 编辑「显示名称（可选）」和「效果描述」，点击「保存说明」。支持撤销、换行、加粗和颜色标记。
4. 关闭并重新打开游戏内说明即可看到修改。状态角标仍由实时状态决定，文案编辑不会施放技能、改变属性或推进回合。

资源位置：`Assets/Resources/BattleTextCatalog.asset`。现有46条数据保留以兼容已有编辑，窗口仅显示仍在使用的条目。主动技能已提供效果文案；状态的空白说明继续采用当前状态自动生成的原说明，可输入自定义正文覆盖。

## 动态变量

- 通用：`{角色名}`、`{层数}`（状态角标）、`{回合}`、`{默认标题}`、`{默认说明}`。
- 主动技能：`{符箓距离}`、`{符箓范围}`、`{传送距离}`、`{治疗量}`、`{治疗距离}`、`{涤尘距离}`、`{涤尘冷却}`、`{姿态冷却}`。
- 元神：`{投掷距离}`、`{清雾半径}`、`{净行额度}`、`{蚀痕间隔}`、`{蚀痕代价}`。

示例：`{角色名}的反伤比例为{层数}。`。说明或标题留空时保留原有自动文案。未知变量保留原样，替换后的内容不会二次展开。

## 实现与验证

文案独立保存在ScriptableObject中，通过Resources加载，接入状态图标名称、状态详情和主动技能/元神按钮的长按说明。守/攻形态、飞行/落地分别配置，原有动态状态层数和规则计算继续独立运行。保存只针对该文案资源。

- 全部运行时、编辑器编译和M1回归通过。
- `python Artifacts/verify_description_text.py`：7项模板替换、空值回退、富文本、未知变量和只读检查通过。
- `python Artifacts/verify_battle_ui.py --descriptions`：原生资源导入、46个条目唯一性、编辑窗口打开、保存、实际状态详情、重新打开读取新文案、长按技能说明及实际模板参数替换通过；检查过程中不改变战斗状态。
- 结果：`Artifacts/description-text-verification.txt`、`Artifacts/description-ui-verification.txt`。
- 截图：`Artifacts/ui-13-editable-status.png`、`Artifacts/ui-14-editable-skill.png`。截图中的测试文案仅写入隔离验证副本，正式配置保留原说明。
