# 瘴毒与千面教程UI

## 内容与布局

文案参考用户提供的 `G:/.工作夹/笔试紫龙/教程文本/瘴毒.md` 和 `千面.md`。简化为浅色矩形面板：左侧是地块/阶段与元神示意，右侧是分段文字，右上角×，底部「我知道了」。使用标准UGUI Image和Text，不添加纸张、笔刷或装饰效果。

- 瘴气与瘴毒：地面瘴气、回合末叠层、攻击和移动惩罚、满层扣血、离雾减层及飞行期间层数冻结。
- 千面与元神：阶段及元神掉落、携带/吞下/投掷、净行额度、蚀痕叠加与生命代价。
- 说明中的阶段数、攻击百分比、移动惩罚、扣血比例、投掷范围、清雾额度和蚀痕参数读取当前关卡。
- 当前正式配置的两张教程均全文可见；保留滚动区以容纳后续更长文案。

文档中「自动拾取」与当前游戏手动选择携带/吞下的操作不一致，教程采用当前可执行的手动操作；原文「转阶段清除所有效果」尚未实现，未将其写成已生效能力。元神落点按实际附近可用地块表述，不宣称随机。这次只接入教程，没有修改战斗规则。

## 触发及生命周期

- 瘴气：落地角色的移动预览路径经过雾格时提前提醒；也检查实际雾格接触和已有瘴毒，覆盖出生雾格、传送及回合末铺雾。只悬停或远处有雾不触发，飞行穿越雾格不视为落地接触。
- 千面：首次选中或作为攻击目标、我方接近至曼哈顿距离4格内，或镜头首次移到千面并准备播放其技能提示时。
- 每局两个主题各显示一次；同一时刻触发时先瘴毒、后千面，等待逐个关闭。
- 弹窗阻止战斗和镜头继续推进，保留原有busy状态、选中单位和未确认移动。关闭后才继续原协程或恢复操作。
- 重开取消旧协程、关闭旧弹窗并重置教程进度；胜负结束、切换模式及销毁时清理弹窗。
