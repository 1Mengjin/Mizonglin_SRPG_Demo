# 角色与怪物 · 属性特征与设计说明

## 2026-11-02 角色加强定案（当前实现）

- **阿双·守形态**：原守形态防御额外+50%，默认36→54；可相邻普攻，造成50%有效攻击力减防御的伤害，不进行普通反击。
- **阿双·攻形态**：原攻形态攻击额外+50%，默认90→135；受外部伤害且结算后存活时，对伤害来源反击`max(1, floor(当前有效攻击×120%)-来源防御)`，无距离限制。反击、咒言与反伤不再触发此反击，避免循环。防御0、射程2、行动后自伤7的原规则保留。
- **两形态护卫**：实时为曼哈顿距离2以内的所有队友抵挡敌方普攻、反击和主动技能伤害，不在回合开始锁定一人。距离变化立即生效；多个阿双时按距离、实例编号依次选择一人。按原目标结算后的伤害整份转移，不再次按阿双防御减伤；环境、自伤和被动反伤不转移。真正扣血的阿双触发受伤被动，未扣血的原队友不触发。
- **素铃·唤灵**：治疗与涤尘在原效果之外，为技能目标（含原有自选自身）施加1层唤灵，上限3层，跨回合保留。目标实际扣血后清空，每层回复施加者素铃当前有效攻击力的50%；同来源层数先合计倍率再向下取整，默认每层14、3层42。包含瘴毒、自伤、蚀痕和生命代价；回复不超过有效最大生命，在死亡判定前结算，已死亡单位不复活。没有扣血不触发。
- **符生·起咒／咒言**：符生存活时，其他存活队友每实际移动1格获得1层咒言，上限8层；起点不计，预览与取消不写回状态。传送按起终点曼哈顿距离计层。实际扣血后清空，每层向外部伤害来源造成符生当前有效攻击力4%的固定伤害；同来源先合计再向下取整，不扣防御。默认75攻击时8层为24伤害。环境、自伤无外部来源时只清空；护卫转移后只检查实际承伤者的咒言。
- 唤灵、咒言逐层保存施加者；施加后即使施加者死亡，已有层数保留，按记录来源的有效属性计算。死亡清空自身状态；重开清空全部局内层数。结算顺序为实际扣血→清空并回复唤灵→引爆咒言→死亡／转阶段→攻形态反击／原反伤。
- 沿用已实现调整：符箓·镇为150%有效攻击的3×3伤害并晕眩一回合，不清雾；符箓·引为6格队友传送到符生四邻空格，CD3；青羽飞行移动力+1；千面每次阶段复活随机召唤2名腐卒，最终死亡不召唤。

## 1. 先区分“属性”的含义

| 层次 | 内容 | 本期用途 |
| --- | --- | --- |
| 固有属相 | 冰、火、雷、光、暗；敌人可用无属性 | 单位模板自带，保存、读取并展示；不是战斗中随机获得 |
| 基础数值 | 最大生命、攻击、防御、移动、射程 | 直接参与移动与战斗计算，可在配置面板调整 |
| 身份与定位 | 我方/敌方、近战/远程/重甲/轻装等 | 解释单位职责，不额外产生职业克制 |
| 行为特征 | 玩家控制；站桩、追击、守卫 | 决定谁控制单位、敌人如何行动 |
| 运行状态 | 当前生命、位置、是否已行动 | 随本局变化，重开时重建，不回写模板 |

**属相、职业、种类分别描述不同的事。** 例如“暗·重甲守卫·妖物”同时说明属相、职责与形象；“妖物”不等于暗属性，“鸟人”不等于风属性。所有单位使用同一套属性字段，不因怪物外形不同而另建数值体系。

## 2. 属相类别与特征

### 2.1 按已有调研整理的基础类别

下表归纳的是所附调研中的基础规则，不是对原作截至今日全量机制的重新核验。调研还提及幽、神、魔等扩展属相，证据与口径不完整，本 Demo 不纳入。职业也只借用辨识语言，不据此复刻原作职业系统。

| 属相 | 配置值 | 既有调研中的基础关系 | 本 Demo 的形象与表现建议 | 不自动附带的能力 |
| --- | --- | --- | --- | --- |
| 冰 | `ice` | 克火，被雷克 | 霜纹、冷色符文、凝结轮廓 | 减速、冻结、减伤 |
| 火 | `fire` | 克雷，被冰克 | 焰纹、余烬、暖色攻击痕迹 | 灼烧、范围攻击、攻击加成 |
| 雷 | `thunder` | 克冰，被火克 | 闪电纹、折线、明快的动作节奏 | 先攻、连击、额外移动 |
| 光 | `light` | 单向克暗；与冰火雷互不克制 | 日轮、净光、清晰明亮的符号 | 治疗、净化、护卫、免疫 |
| 暗 | `dark` | 被光克；不因“光暗对立”而反向克光 | 蚀纹、暗雾、破碎面具 | 吸血、诅咒、瘴气免疫 |
| 无 | `none` | 作为本 Demo 中不参与克制的中性类别 | 中性纹样及明确“无”字标签 | 免疫元素攻击、隐藏伤害抗性 |

原作基础关系的参考简表：**雷 → 冰 → 火 → 雷；光 → 暗**。箭头只表达方向，不规定本 Demo 的伤害倍率；同属相、无属性，以及光暗与三元素之间均不据此增加本期计算分支。

不添加“风、木、毒”属相。御风是职业/定位语言，树木是形象，瘴毒是状态，均不应直接混入属相枚举。

### 2.2 本期实际生效口径

- 每个模板恰有一个属相；我方从冰、火、雷、光、暗中选择，敌方另可选择无。
- 同一模板的所有实例继承同一属相。改模板、保存并重开后统一更新；本局中没有变身改属相、双属相或临时附魔。
- 默认 7 个模板覆盖五种基础属相；不要求每一方都覆盖五类，也不要求额外添加第 8 个模板来展示无属性。
- **无论攻击方和防守方属相如何，普攻和反击均采用 `max(1, 攻击 − 防御)`。** 属相不改攻击、防御、移动、射程或危险格伤害。
- UI 必须提示“属相仅作标识，当前版本无克制加成”，避免玩家按原作克制经验计算伤害。

## 3. 共用数值与状态字段

### 3.1 固有数值

| 字段 | 含义 | 校验 | 设计上决定什么 |
| --- | --- | --- | --- |
| `maxHp` | 最大生命 | 正整数 | 可承受的攻击次数；危险格扣血的计算基数 |
| `attack` | 攻击 | 非负整数 | 单次普攻及反击的输出 |
| `defense` | 防御 | 非负整数 | 承受普攻及反击时的固定减伤 |
| `move` | 单次行动移动上限 | 非负整数 | 赶路、接敌和撤离能力；0 表示不能移动 |
| `range` | 普攻最大射程 | 正整数 | 满足 `1 ≤ 曼哈顿距离 ≤ range` 时可攻击 |
| `guardRadius` | 敌方守卫活动半径 | 非负整数，仅守卫使用 | 限制守卫可移动与索敌的区域，以出生点为锚点 |

“重甲”不另附减伤，“轻装”不另附闪避；数值表已经承担其差异。当前只有一套攻击和防御，不拆物攻/法攻、物防/法防，也不加入命中、暴击、速度、等级与养成字段。

守卫 AI 的“守卫”表示区域限制，不表示替同伴承伤；角色定位中的“坦克/铁卫”也不自动获得护卫技能。

### 3.2 战斗中的变化

`currentHp`、`x/y`、`acted` 为运行状态；死亡由当前生命归零或以下判定并移除单位。模板保存最大生命，不保存残血。属相从模板读取，避免模板和实例分别存储后出现不一致。

危险格属于地图规则：每次主动行动结束，按最大生命的配置百分比向上取整扣血。所有属相按同一规则承受，不因火属性免疫危险格、光属性免疫瘴毒等形象联想而产生例外。

## 8. 迷踪林设计稿的候选补充

目录中的[灵感稿](灵感.md)与[地块方案](设计稿/地块结构方案.md)采用迷踪林四人小队、机制怪与清雾目标。以下为其**候选固有属相与特征归类**；最小 Demo 模板仍见 PRD，两套生命、攻击数值不合并。完整单位说明已分别整合至上述角色、怪物文档。

| 单位       | 候选属相 | 现有职责与特征          | 属性设计边界                                |
| -------- | ---- | ---------------- | ------------------------------------- |
| 符生       | 火    | 远程输出、晕眩、传送与起咒   | 清雾来自明确技能，不是火属相自带能力；原稿“法师”与调研“咒师”术语需统一 |
| 素铃       | 光    | 祝由；治疗、清除单位瘴毒并叠加唤灵   | 光不自动清地面雾，治疗与驱散分别消耗行动                  |
| 青羽       | 雷    | 御风；飞行运输元神、落地攻击   | 雷不等于风；飞行来自专属规则，不能由属相推导免伤或不可被攻击        |
| 阿双       | 冰    | 铁卫；按周期切换攻守，两形态均护卫2格队友    | 双生不意味着双属相；形态变化先不改固有属相                 |
| 树精 A / B | 暗    | 原地蓄力造雾、受击催熟；两处雾源 | 同类模板可共享属相；木质外形不新增木属相，催熟与根须不由暗自动赋予     |
| 吞噬怪（雾行者） | 暗    | 固定巡逻、吸雾、携雾、死亡泄雾  | 携雾量是独立状态；瘴气免疫若保留，须来自明确机制              |
| 千面       | 暗    | BOSS、阶段掉落元神      | 不因多个阶段自动改属相；阶段机制与掉落规则另行定义             |
| 腐卒       | 无    | 低机动占位、消耗玩家清路行动   | 无属性不是免疫；不把“移动较低”写成“绝不构成威胁”            |

这套分配强调“光与侵蚀”的辨识，未追求敌我均覆盖五属相。若以后加入克制，暗属相集中可能使光角色收益过高，必须结合素铃的低输出与治疗行动成本重新测试，不能直接沿用当前数值判断平衡。

迷踪林仍待补齐的数值包括角色防御、治疗量、树精与 BOSS 的完整战斗属性、吞噬怪携雾增长阈值等；本次不以未经验证的数值填成定案。青羽飞行受击规则、阿双自伤与承伤结算也需要单独明确，不能靠属性标签补足。

## 9. 来源与设计结论的边界

- **从 PRD 继承：** 7 个 ID、阵营与基础数值、三类 AI、通用伤害和反击、危险格口径。
- **从调研摘要整理：** 五种基础属相、敌方无属性、雷冰火循环与光单向克暗；保留原调研的参考性质，不视为新增官方核验。
- **本次新增提案：** 7 个原创暂名、固有属相分配、形象提示、属相字段与展示校验，以及迷踪林候选属相。
- **未宣称完成：** 程序实现、整局平衡、两种通关思路成立及 3–8 分钟实测。本文提供配置与设计口径，实际结果仍需试玩。
