## 关卡设计

Unity菜单：**紫龙 Demo → 关卡设计**。编辑与Play共用正式配置。

技能和状态文案：**紫龙 Demo → 技能与状态说明**，也可点击关卡设计窗口或BattleDemo Inspector中的「编辑技能与状态说明」。选择「反伤」「瘴毒」等条目，修改说明标题及效果描述，点击「保存说明」；关闭并重新打开游戏中的说明即可看到修改，无需修改代码或重开战斗。配置为`Assets/Resources/BattleTextCatalog.asset`。名称/描述留空使用原有自动文案，`{默认说明}`保留动态状态说明，`{角色名}`、`{层数}`及技能距离等变量会自动替换。修改仅影响文字展示。

- **地图与出生点**：选择画笔；我方/敌方放置列表分别使用4种正式模板。支持移动/删除出生实例、区域、初始瘴气、根须和有序巡逻点。格子可缩放，地图可横向滚动；也可在Scene中逐格绘制。
- **奖励地块**：画笔“奖励地块”放置到无出生点的可走格，“删除奖励”移除；格子标注“奖”，Scene预览显示彩色闪光。当前在出生区(4,10)放置一格。我方确认移动并停在格上拾取一次；路过、预览与取消不消耗。拾取后仅播放2秒“获得奖励”回弹弹窗，不改变属性或资源；重开恢复。
- **单位模板**：按我方、敌方、全部筛选。编辑名称、职业、头像、属相和基础属性，以及对应角色/怪物的专用参数；页面显示引用此模板的实例。树精、吞噬怪及千面均无普攻。千面每阶段生命随最大生命同步，伤害改由蓄力技能产生。
- **关卡规则**：集中编辑瘴毒、濒死、根须、元神投掷范围、清雾半径、净行额度及蚀痕代价；选择根须来源实例。上述参数已参与对应结算。

修改支持Unity撤销；点击「保存并刷新场景」提交。点击「保存并开始试玩」保存后进入Play。非法配置会提示具体错误并阻止保存/Play。逐格操作不再反复重建并保存整个场景。恢复默认地图与布置会保留已编辑的单位模板与规则，可撤销。

地图坐标左上角为(0,0)，向右X增加、向下Y增加。默认18×14，149格连通可走格，15格初始雾。吞噬怪正式出生在(15,6)，下一巡逻点为(16,6)。

千面每次阶段复活后，在自身周围8格的随机可走空位召唤1名腐卒，避开单位与地面元神；空位不足按实际数量召唤，最终死亡当回合末在(15,1)、(16,1)、(15,2)、(16,2)中随机选择两个不同的首选点生成腐卒，整局只生成这一波；首选点被单位、元神或障碍占用时，在全图可走空格中按距该点的曼哈顿距离、y、x选择最近落点。同批次不重叠，战斗结束停止；全图无空位时记录缺额。腐卒使用正式模板属性和原追击行为。青羽飞行状态移动力+1，落地恢复原值；瘴毒的移动惩罚仍正常计算。

符箓·引改为传送：先选曼哈顿距离6格内的另一名存活队友，再选择符生上下左右的一个可走空格；消耗符生的主要行动，冷却3回合，队友原有行动状态保持。可在关卡设计调整传送距离。

角色加强：阿双守形态移动力-1，防御在原数值上+50%（默认54），保留普攻折半且不降低攻击属性，攻形态攻击在原数值上+20%（工厂默认108），最大生命+50%、受到伤害+30%，切换形态时按当前生命比例换算，实际受外部伤害后反击120%有效攻击力减防御的伤害；两形态实时护卫2格内队友。素铃治疗、涤尘为目标叠1层唤灵（上限3），实际扣血清空，每层回复50%素铃有效攻击力生命。符生起咒：其他队友每移动1格叠1层咒言（上限8），传送按起终点距离计层；实际受伤清空，对外部来源造成每层4%符生有效攻击力的固定伤害。环境与自伤没有外部来源时仅清空咒言。被动伤害不继续触发攻形态反击。

## 试玩操作与规则

- 教程：首次预览经过瘴气地块、实际站入瘴气或已有瘴毒时，弹出「瘴气与瘴毒」；首次接近千面4格内、选中/攻击千面，或看到千面施法前，弹出「千面与元神」。每局各一次，重开重置。采用左侧简图、右侧机制说明、右上关闭的简易布局；点击×、「我知道了」或Esc关闭，随后继续原来的操作。弹窗期间锁定战斗与镜头，不确认移动预览。
- 顶部只常驻显示回合数，使用半透明黑底；技能预览和敌方范围说明按需显示在底部提示区。角色状态栏只展示已经生效的Buff、Debuff和标记：瘴毒、蚀痕、晕眩、唤灵、咒言、反伤、净行、飞行/形态、携带元神、蓄力等；不再展示预览、行动、技能次数/冷却、常驻被动和千面阶段说明。没有效果时收起整个状态区，移动预览副本中的未提交效果不进入状态栏。点击效果可查看说明。
- UI使用屏幕覆盖绘制与像素对齐，默认窗口1920×1080；圆形控件精度和模型头像渲染提高到512像素。只有回合切换使用58%黑色全屏遮罩；胜利条件及双方技能提示使用独立矩形边框，72%半透明黑底仅限框内。低分辨率的Game窗口放大显示仍受原始像素数量限制。
- 开局先播放胜利条件横幅：从右侧滑入、居中停留4秒，再向左滑出；内容使用当前关卡「清空当前场上全部瘴气」的目标。随后播放我方回合徽章。
- 我方/敌方回合切换使用青绿「阳之阵」/朱红「阴之阵」徽章及回合数；动画结束后才执行下一方行动，我方阶段开始结算也等待徽章结束。
- 主动技能在结算前播放技能名横框及当前角色头像：头像从左侧弹入并短程回弹，完整停留1秒后与横框一起消失。免费姿态切换、疾行也接入，保留移动预览与行动次数规则。
- 千面蓄力、震击，以及回合末实际触发的树精爆果/吞噬怪吸雾/吞噬怪自爆，会先将镜头平滑移至施法者，再显示顶部图标及技能名。自动技能通过独立状态副本预判，正式回合末仍按原批次结算。提示期间锁定交互及手动拖镜头，重开清理旧提示并重播开场。
- 青羽初始落地。点击「展翼／收翼」技能，不消耗或恢复行动次数；本回合姿态不变，下回合开始自动切换，冷却1回合（N回合使用，N+1回合恢复）。没有使用技能时保持当前姿态，不再出现阶段开始的选择弹窗。
- 点击我方选中，点击可达格预览移动；点击射程内敌人直接普攻。路径、根须费用与移动预算共用判定。
- 右下技能按钮：符生使用符箓镇或符箓引；素铃使用治疗或涤尘；青羽使用姿态切换或疾行；阿双使用退去。点击后按提示选择目标或位置，原有自选目标规则保留。左键长按技能0.5秒显示占位描述，松开或移出后关闭，长按结束不施放技能。
- 符生、素铃、青羽和阿双的角色卡已接入`Assets/Art/Portraits`中的对应头像，正式模板使用同一组图片引用。
- 头顶改为角色/怪物名称，使用半透明黑底、加粗文字、数值血量和实体血条；低血量变色，扣血保留黄色残影。伤害及治疗使用大号描边、黑底飘字并向上淡出；前冲施放、受击闪烁/震动、死亡缩小和敌方沿路径移动只影响表现，不改结算和逻辑位置。此轮只做编译与逻辑回归，未做试玩或画面验收。
- 每个行动机会允许移动和一次主要行动；普攻、符箓镇、符箓引、治疗、涤尘和退去共用主要行动，待机也结束该次机会。青羽姿态切换和疾行免费；疾行增加本回合一次完整行动机会（含移动），CD2，N回合使用后N+2恢复。使用时不提交正在预览的移动；手动结束回合会将所有剩余机会待机结算。
- 符箓镇正式配置射程2、3×3范围、全关2次（工厂默认射程3、全关1次），删除清雾效果。范围内敌人受到150%有效攻击减防御的伤害，并晕眩1回合；晕眩期间该敌人无法进行任何操作（技能、移动、普攻、自爆），只会待机，约等于把行动延后一回合；被击杀时不触发亡语（吞噬怪不泄雾），千面阶段转换不按亡语处理。树精自动成长、自动爆果与受击落地、吞噬怪吸雾在晕眩期间全部暂停；解晕后恢复，可用沉默提前预防这一轮瘴气生成。
- 阿双守形态可主动攻击身旁四格的一名敌人，按50%有效攻击减防御结算，仍不反击。退去消耗主要行动：守形态为下次来自其他单位的伤害准备90%反伤；攻形态扣除30%当前有效最大生命（向上取整，需保留至少1点生命），造成实付生命120%的固定伤害，目标在当前普攻射程内。原有攻形态行动结束自伤保留。
- 符箓·引选择正式配置7格内（工厂默认6格）的另一名存活队友，再指定符生上下左右的可走空格传送，CD3，从使用回合N+3恢复；保留被传送队友原有行动状态。
- 千面有4阶段，每阶段生命随模板最大生命同步（正式配置110、工厂默认120）。击破一阶段立即生成1颗元神并进入下一阶段，溢伤不带入；第四阶段击破后死亡。同回合其他角色仍能攻击新阶段。掉落按距离1–3、正上起顺时针搜索空的可走格；全堵则保留待掉落记录，行动后重试。
- 元神不再自动拾取。落地角色脚下或本次移动路径有元神时，可选择「携带」或「吞下」，最多携带1颗；携带后可投掷，也可再吞下。携带、吞下和投掷均不消耗或恢复行动次数，已完成主要行动的角色仍可操作。移动预览中操作元神会确认这次移动，但保留主要行动，不能因此获得第二次移动。「投掷」射程4，落点可走且无其他单位，无视视线，清除曼哈顿半径2内的地面雾，不伤人、不清单位状态。「吞下」获得12格净行额度，不立即清脚下雾。
- 净行只随落地实际移动生效，包含起点与终点；仅成功清除雾格才扣额度。每份额度独立排队，每清4/8/12格增加一层蚀痕，同时最大与当前生命减少10，最低1；12格用尽立即停止使用该份额度。蚀痕不可驱散，瘴毒及濒死按削减后的最大生命计算，阿双自伤仍按模板生命计算。飞行暂停净行且不能拾取、投掷或吞下元神；死亡移除净行并将携带元神掉在死亡格。
- 移动预览在独立副本上试算清雾、蚀痕和生命变化；确认移动中的元神操作或主要行动后提交。提交前取消不会改变真实资源与状态；已确认的元神操作和青羽免费姿态切换保留。全部主要行动完成后自动进入敌方阶段，携带或脚下有元神不会阻止自动结束；未使用的携带元神保留到下回合。
- 右键短按或Esc取消当前技能选取/移动预览；按住右键拖动镜头。点击脚下格子进入移动预览时也显示取消键；取消后可重新选择落点。
- 「结束回合」使未行动者原地待机，随后进入敌方阶段与回合末；攻形态阿双即使被跳过也自伤。
- 「重开」从本局初始快照重建生命、位置、状态和技能次数，不将残血、冷却或形态写回配置。
- 右上「悔棋」按角色计算：撤回最近一名行动角色本回合的全部操作，最多回退 3 步。回退会连同该步之后的敌方阶段与回合末结算一起撤销；随机状态同步还原，重复相同操作时敌方按原样重演。本局用时与教程已展示标记不回退；敌方阶段、动画与结算期间不可用，重开清空。结束回合不单独记作一步，误按时可悔棋回到最后一名行动角色操作前，该角色可立即重做。
- 选中敌人可查看作用范围：腐卒显示移动后普攻威胁，树精显示当前果级铺雾范围，吞噬怪显示吸雾范围，千面区分可能蓄力方向与已锁定红色预警。已锁定边框保留，不被技能选取颜色遮住。伤害预览及飘字按实际扣血量显示，理论伤害保留在事件CSV。
- 右上「战斗记录」可查看本回合、污染与资源、本局统计；滚动查看，按Esc或「关闭」返回。可将策略标记为自由测试、集中突进或分兵除源，仅用于记录，不改变玩法。长按技能仍显示用户要求的占位描述。
- 计时累计前台聚焦期间的游戏用时，包含思考、查看记录和结算；失去焦点暂停，战斗结束停止，重开归零。胜负界面显示行动、资源、损失、濒死历史和除源回合，并可查看记录。结束或中途重开自动保存战报，也可手动导出；文件位于`Artifacts/ForestRuns`，包含Markdown汇总和完整逐笔CSV、起始布置及随机种子。

当前已实现：整数伤害、严格一次反击、符箓全关次数、治疗/涤尘及冷却、青羽姿态、阿双自动攻守/实时2格护卫/120%受伤反击/伤害转移/不致死自伤，以及唤灵与咒言被动、普通瘴毒回合末层数与掉血、濒死历史和费用寻路。角色卡显示基础值→有效值。

**敌方阶段按实例ID顺序行动。** 树精维持蓄力；吞噬怪按配置巡逻，目标格被占时等待且不推进索引；千面无普攻，随机选存活玩家的方向，在身旁相邻的3×3区域预警并蓄力，下一敌方阶段对固定区域内所有单位造成60点伤害，预警不跟随目标移动；腐卒按到可攻击位置的最短路径费用追击，费用相同按角色ID、攻击位置y/x排序，移动后在射程内攻击一次。所有路径遵守单位占位和根须费用。
